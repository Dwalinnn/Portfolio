VAT addon

to convert anything (or almost) in Vertex Animation Texture

This is the result of my master degree research. This C# addon for Unity will help you convert various alembics animations into VATs with LODs.

https://github.com/Dwalinnn/AlembicToVATwithLOD_Baker

This Tool works for fixed topology only and still need a fix in the code to be able to run RBD with a island aware filtering for vertex groups

This is a showcase of LOD integration for VAT and a proof that it can help to optimise even more Vertex Animation Texture
